## Issue 295 implementation

`saveCollectionDraft` now prepares the merged source list before a pending write, using the existing `prepareSourceLinks` validator. It covers explicitly sent, pending-inherited and live-inherited lists. Duplicates merge before the cap. Nothing truncates a list to make it publishable. Errors identify the inherited origin and raw row count and request corrected `sources`; explicit invalid input retains the canonical source error. Other entity writers and publication guards are unchanged.

Before the fix, four of five [isolated writer-boundary cases](../../../apps/web-app/test/pending-collection-sources.test.ts) failed. All five now pass: inherited live/pending over-limit lists, no draft/audit write on refusal, explicit repair/clear, duplicate rows, malformed inherited rows and direct invalid input. These mock persistence, not the collection writer being exercised.

The [Postgres writer suite](../../../packages/database/src/repository/test/pending-collection-route.writer.test.ts) also covers refusal without a new pending draft/audit, preservation of an old invalid pending payload, explicit repair, unchanged live data until editor publication and successful application. Its existing independent publish-time guard still rejects a legacy/raw invalid payload; early staging validation does not replace that guard.

## Read-only audit

[report-source-lists.ts](../../../apps/web-app/scripts/report-source-lists.ts) scans stored place/collection/venue lists and top-level pending source lists (including legacy routes) using the canonical validator. A route has no source column. It uses `BEGIN READ ONLY` and rolls back, never runs migrations, trims lists or applies drafts. The result contains row identity/count/problem, not full page bodies. Duplicate URLs are validated before deciding that a row is over the cap.

Run against an explicitly selected database with its existing authorized operator environment, without printing credentials:

```bash
pnpm --filter @k39/web-app exec jiti scripts/report-source-lists.ts
```

`DATABASE_URL` is required; the script does not guess one. A live audit has not been run here. The report's old three collections were reportedly repaired by hand; no current remaining production count is asserted. Venue nested staged fields are outside this report's top-level pending scope; their validator is separate.
